# Tic-Tac-Toe Game in C

A simple Tic-Tac-Toe game programmed in the C language where the user inputs characters row-wise, and the program evaluates the board at the end to declare either a winner or a draw.

### Key Features & Concepts:
* **2D Arrays & Nested Loops:** Used to create and navigate the 3x3 game board matrix.
* **Optimized Evaluation:** Employs precise `if-else if-else` statements to instantly validate all win conditions (rows, columns, and diagonals).

This project was built as a fundamental task to master multi-dimensional array mapping, coordinate concepts, and logic building in C programming.
